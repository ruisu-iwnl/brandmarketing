# E-COMMERCE PROJECT

built with Next.js 15, TypeScript, and Tailwind CSS.

## Tech Stack
- **Framework**: [Next.js 15](https://nextjs.org/) (App Router)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Font**: Geist Sans & Mono

## Project Structure
- `src/app/`: Routing and layout.
- `src/components/sections/`: Modular landing page sections (Hero, Shop, Contact, etc.).
- `src/components/`: Reusable UI components (ProductCard, Modals, etc.).
- `src/data/`: Static data sources (Product catalog).
- `public/`: Static assets (images, icons).
